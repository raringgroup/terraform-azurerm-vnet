# terraform-azurerm-vnet

Creates one Azure virtual network, named and tagged through the Raring Group context module. Subnets are created by the `subnets` module.

Part of the [Raring Group](https://github.com/raringgroup) Terraform module library.

## Usage

```hcl
module "vnet" {
  source = "git::https://github.com/raringgroup/terraform-azurerm-vnet.git?ref=v0.1.0"

  context = module.context.self

  address_space       = ["10.0.0.0/16"]
  dns_servers         = []
  location            = azurerm_resource_group.this.location
  resource_group_name = azurerm_resource_group.this.name
}
```

Naming and tagging come from [`terraform-null-context`](https://github.com/raringgroup/terraform-null-context). Add `_context.tf` to the calling configuration and pass `context = module.context.self`.

The module uses `azurerm_virtual_network` directly. Naming, tags and the enabled flag come from the context module. `_context.tf` declares the root context (`git::https://github.com/raringgroup/terraform-null-context.git?ref=v0.1.0`); the child context in `vnet.tf` uses the same source.

See [`examples/`](examples/) for complete, runnable configurations.

## Requirements, providers, inputs, outputs

### Requirements

| Name | Version |
|------|---------|
| terraform | `>= 1.3.0` |
| azurerm | `>= 4.0.0, < 5.0.0` |

### Inputs

All inputs are required (no defaults). Context inputs (`enabled`, `namespace`, `environment`, `stage`, `name`, `attributes`, `tags`, ...) are declared in `_context.tf`.

| Name | Type | Description |
|------|------|-------------|
| resource_group_name | `string` | Resource group that holds the virtual network |
| location | `string` | Azure region where the virtual network is created |
| address_space | `list(string)` | CIDR blocks that make up the address space |
| dns_servers | `list(string)` | Custom DNS server IPs; an empty list uses Azure-provided DNS |

### Outputs

| Name | Description |
|------|-------------|
| id | Virtual network ID (null when disabled) |
| name | Virtual network name (null when disabled) |
| address_space | Virtual network address space (null when disabled) |
